# OOP Logic Practice

Three progressively complex Python projects built to solidify 
Object-Oriented Programming concepts from first principles.

## Projects

### 1. Library System
Members borrow and return books. Tracks availability and borrowing history.
**Concepts:** Classes, instance attributes, object passing between methods

### 2. School Attendance
Students enroll in teacher classes. Teachers mark and report attendance.
**Concepts:** Cross-class interaction, dictionaries for state tracking

### 3. Company Project Manager
Employees assigned to projects with budget enforcement and team reporting.
**Concepts:** Running totals, duplicate checks, storing objects in lists

## What I Learned
- How to connect two classes by passing objects as parameters
- Who owns what data — and why that determines where methods live
- Defensive programming — checking state before allowing actions
